subwaydata.nyc hosts a growing dataset of train times for the New York City subway starting April 1, 2021. For each trip that runs in the subway, the dataset records the list of stations the trip called at and the times it stopped. The dataset is automatically updated every morning with data from the previous day.

Browse the data to get started.

by Tim Gouw via Unsplash

The dataset is built using the GTFS realtime data feeds published by the MTA. Its structure is described in the data schema page. The raw GTFS realtime data is also available for download. The how it works page describes the software systems that power the project.

All of the software used (including this website) is open source and adaptable for other transit systems. If you use the dataset for a public project, please cite subwaydata.nyc accordingly.
